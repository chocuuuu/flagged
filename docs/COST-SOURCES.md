# COST-SOURCES.md

The cloud pricing notes in the repository were last checked on 2026-10-08. They are historical references, not current pricing confirmation and not a basis for a zero-cost guarantee.

Before any optional live deployment, independently check the official pricing and billing requirements for every selected service, region, resource configuration, and external workflow. Verify the current official:

- Cloud Run pricing
- Pub/Sub pricing
- Firestore pricing and quotas
- Cloud Logging pricing
- IAM pricing
- Artifact Registry pricing
- Cloud Storage / GCS Terraform state pricing
- Secret Manager pricing
- Memorystore for Redis pricing
- Cloud SQL pricing
- GitHub Actions hosted-runner terms and usage limits

Free quotas are not cost caps. The standard project path uses local services, emulators, and local validation; no pricing assumption is needed to complete it.
